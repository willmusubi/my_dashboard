# 模型与 Agent 路由

这份文件定义的是决策权责。实际可用的模型取决于用户的工具与订阅方案。

## 高推理模型

用于：

- 模糊的产品决策。
- 系统设计。
- 跨服务变更。
- 架构取舍。
- 安全性敏感的推理。

范例：

- Claude Opus 级模型。
- 高推理等级的 Codex 模型。

## 快速通用模型

用于：

- 小型实作任务。
- 文件更新。
- 新增测试。
- 简单重构。
- Mockup 草稿。

范例：

- Claude Sonnet 级模型。
- 快速版 Codex 模型。

## 审查 Agent

用于：

- PR 审查。
- Diff 审查。
- 安全性审查。
- 回归分析。
- 测试缺口侦测。

## 路由规则

- 高风险任务不得在没有审查的情况下交给低成本的实作模型。
- 不得让同一个 agent 既负责实作、又是唯一的审查者。
- 杂讯多的搜寻或大范围调查要用独立的情境（context）进行。
- 规格书、情境包与验收标准都清楚之后，优先使用成本较低的模型。

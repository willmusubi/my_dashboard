# AI-Ready 任务卡范例

## Metadata

- 任务：为项目列表新增空状态
- 上层规格：项目仪表板
- 状态：就绪
- 风险等级：低
- Agent owner：实作 agent
- 人工批准者：产品负责人

## 目标

当用户没有任何项目时，显示一个空状态画面，并附上清楚的「建立项目」动作。

## 情境包（Context Pack）

- 相关文件：
  - `src/pages/projects/*`
  - `src/components/project-list/*`
- 既有模式：
  - 重复使用既有的按钮与 modal 组件。
- 假设：
  - API 在没有项目时已经会返回空数组。
- 未知事项：
  - 无。
- 允许变更的文件：
  - 项目列表组件、相关测试档。
- 不得触碰：
  - 身分验证、路由、数据库 schema。

## 需求

- 显示空状态标题、简短说明，以及建立动作。
- 点击建立会开启既有的建立项目 modal。
- 手机版排版不可溢出。

## 验收标准

- 只有在项目数量为零时才出现空状态。
- 既有的非空列表行为不受影响。
- 建立动作会开启 modal。
- 测试涵盖空与非空两种情境。

## 验证契约

- 单元测试：项目列表的空／非空状态。
- 屏幕截图：桌面版与手机版的空状态。
- Lint：项目的 lint 指令。
- Build：项目的构建指令。

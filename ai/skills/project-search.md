# 项目搜寻

在规划或实作非小型（non-trivial）工作之前使用此流程。

## 步骤

1. 若存在，先阅读 `ai/context/project-map.md`、`ai/context/architecture-map.md` 与 `ai/context/code-search-guide.md`。
2. 确定精确的搜寻词：符号（symbol）、路由（route）、组件名称、API 路径、错误消息。
3. 优先使用 `rg` 及具符号感知能力的工具，例如可用时的 Serena MCP。
4. 只阅读最小范围的相关文件集合。
5. 依照 `ai/process/context-protocol.md` 产出情境包。
6. 仅在发现具持久性价值时，才更新 `ai/context/code-search-guide.md`。

## 输出

```text
任务：
相关文件：
既有模式：
假设：
未知事项：
允许变更的文件：
不得触碰：
验证指令：
风险等级：
情境预算备注：
```

# 安全性检查清单

无论任务风险等级高低，在撰写代码的当下就要套用这份列表——不是只有高风险工作的正式安全性关卡（Security Gate）审查时才用。

- 对照 OWASP Top 10（权限控管失效、加密机制失效、注入攻击、不安全的设计、安全设定错误、使用有漏洞或过时的组件、身分验证失效、软件与数据完整性失效、记录与监控不足、SSRF）逐项检查。
- 绝不以明文存储密码或密钥。密码要杂凑处理（例如 bcrypt/argon2），金钥／权杖要从密钥管理服务或环境变量载入，不要写在原始码里。
- 验证所有外部输入。
- 检查身分验证边界。
- 检查每个受保护动作的授权。
- 不要记录密钥或敏感个人数据。
- 不要写死（hardcode）凭证。
- 检查文件上传、文件路径与指令执行行为。
- 检查网络调用与外部 URL。
- 检查注入风险：SQL、XSS、指令、样板、路径穿越（path traversal）。
- 视情况检查 CSRF 与 CORS。
- 检查依赖包与供应链风险。
- 检查迁移（migration）与回滚（rollback）安全性。
